# Aruvi E-Sevai Maiyam (அருவி இ-சேவை மையம்) - Kovilpatti

A complete, responsive, frontend website for **Aruvi E-Sevai Maiyam**, an E-Sevai and Unorganized Workers Welfare service centre located in Kovilpatti, Tamil Nadu.

The website provides an original, professional design inspired by the layout structure of modern tech leaders, tailored specifically for Indian public civic services with a light, welcoming aesthetic.

### 27 Service-Specific Application Forms (`apply/*.html`)
Every service has its own dedicated application form:
- Simplified applicant fields: Full Name, 10-digit Indian Mobile Number, Address, Work Type dropdown (9 options), and conditional "Specify Your Work" when "Other" is chosen.
- Unnecessary fields removed (no welfare board card numbers, bank account numbers, IFSC codes, document file uploads, or confirmation checkboxes).
- Client-side browser validation with instant error clearance.
- **Frontend Submission Compliance Modal**:
  - Displays: **"Backend connection required to submit your application."** / **"உங்கள் விண்ணப்பத்தைச் சமர்ப்பிக்க Backend இணைப்பு தேவை."**
  - Explains that this frontend demo does not process personal data or store data to a database.
  - Informs the applicant to visit the Kovilpatti office with original documents for in-person submission.

## 🚀 Running Locally

The website is pure HTML5, CSS3, and Vanilla JavaScript. It requires no build tools or package dependencies to run.

You can serve it with any static server:
```powershell
# Using Node.js built-in server (provided in workspace):
node server.cjs
```
Then visit:
```
http://localhost:5174/
```
